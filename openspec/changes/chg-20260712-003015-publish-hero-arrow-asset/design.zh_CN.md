## 背景

英文首页的 `.hero-panel-v2` 按钮通过 `::after` 伪元素加载 `assets/icons/homepage/hero-arrow.svg`。源 SVG 存在，但静态构建的资源白名单遗漏了它，因此生成的 `public/` 目录会对该 CSS 背景 URL 返回 404。

`hero-panel-v2` 仅用于英文首页。法文兼容首页不使用该选择器，因此仅向英文输出发布资源可保持现有的版本资源边界。

## 目标 / 非目标

**目标：**

- 在生成英文 CSS 所引用的 URL 发布现有箭头 SVG。
- 恢复 Hero 按钮预期的箭头，不改变 CSS 选择器、标记或链接行为。
- 将生成资源的存在作为站点渲染契约。

**非目标：**

- 重新设计 Hero 按钮，或以文字、其他图标替换该 SVG。
- 发布未使用的旧首页图标。
- 修改法文输出、响应式规则、导航或源 SVG 图稿。

## 决策

### 将现有源资源作为仅英文资源发布

将 `icons/homepage/hero-arrow.svg` 加入 `ENGLISH_ONLY_PUBLIC_ASSET_PATHS`。

生成的英文 CSS 会将相对 URL 精确解析为 `public/assets/icons/homepage/hero-arrow.svg`，该清单项会生成该文件。未选择共享清单，因为法文首页不使用该选择器；未选择使用文字箭头或现有 sprite，因为两者会改变已批准的箭头图稿，或引入不必要的标记和样式变更。

### 将构建测试改为正向契约

站点渲染脚本将断言英文生成资源存在，并保留法文资源不得存在的断言。

这样可撤销导致生产输出损坏的过期负向断言，同时保持项目的选择性公开资源策略。

## 风险 / 权衡

- **后续资源清理移除了清单项。** → 正向生成资源断言会在站点验证中失败。
- **资源泄漏到法文输出。** → 现有的法文资源缺失断言继续保留。
- **SVG 内容意外变化。** → 本变更复用现有源文件，不复制或编辑图稿。

## 迁移计划

1. 构建站点以生成 `public/assets/icons/homepage/hero-arrow.svg`。
2. 通过现有静态站点发布流程部署。
3. 如需回滚，移除仅英文资源清单项并恢复原测试预期；不涉及 URL 或数据迁移。

## 开放问题

无。
