## ADDED Requirements

### Requirement: 首页西非地图概览必须对齐已批准的西海岸参考构图
英文版首页必须将地图概览模块渲染为已批准的西海岸政治地图参考构图：左侧是紧凑的导语文案块和蓝色 `Explore the Map` CTA，右侧直接使用用户提供的西非政治 SVG，包括图内自带的佛得角 inset 与可见国旗，而不是当前抽象的大陆多边形。

#### Scenario: 桌面端布局遵循批准构图
- **WHEN** 英文版首页在桌面端渲染
- **THEN** 地图概览模块在较窄的左栏呈现标题/正文/CTA，在右栏呈现政治地图面板
- **THEN** 右栏展示原始 SVG 中的佛得角 inset、可见国旗以及西非西海岸政治底图，而不是通用裁剪陆块
- **THEN** 该模块 CTA 使用批准的蓝色处理，而不是默认的橙色主按钮样式

#### Scenario: 国家热点保留既有目标路由
- **WHEN** 用户点击地图概览面板上的任意国家热点
- **THEN** 跳转目标与对应首页国家卡片使用的国家分析路由完全一致
- **THEN** 键盘聚焦和 hover 会显示可见的热点提示，同时保证每个热点都以用户提供 SVG 中对应国旗为中心对齐

#### Scenario: 西海岸小国在不遮挡边界的前提下保持可辨识
- **WHEN** 地图概览面板渲染边界过于紧凑、无法把国旗直接放进国家内部的西海岸小国
- **THEN** 面板 MAY 将该国的可见国旗略微偏移到边界外侧
- **THEN** 面板 MUST 通过明确的视觉关联把国旗指回目标国家，例如国家内部锚点加短引线

#### Scenario: 国家卡片在独立首页输出中仍保留国旗
- **WHEN** 英文版首页渲染国家卡片
- **THEN** 文档内包含这些卡片所需的共享国旗 sprite 定义
- **THEN** 每个国家卡片国旗都引用类似 `#nigeria` 的本地片段 ID，而不是外部 `/assets/icons/country-flags.svg#...` URL

#### Scenario: 窄视口下仍保持可读
- **WHEN** 首页在平板或手机宽度下渲染
- **THEN** 地图概览文案与地图面板以堆叠方式呈现，不裁切地图画面或 CTA
- **THEN** 政治地图图片按比例缩放，热点跳转仍然可用
