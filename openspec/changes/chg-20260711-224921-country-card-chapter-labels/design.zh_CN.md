## 背景

`scripts/shared/homepage-content.mjs` 保存 `COUNTRIES` 元数据并渲染英文首页国家卡片。每张英文卡片已经拥有稳定的章节 URL 与片段锚点，但可见文案均为“Country Analysis”。`public/` 是生成产物，禁止直接编辑。

UA-14 提供了已发布英文版的 16 个国家—章节映射。法文兼容首页不渲染这组卡片，并链接到不同结构的章节，因此不属于本次变更范围。

## 目标 / 非目标

**目标：**

- 让每张英文国家卡片链接显式标明其已发布的 `Chapter 3.X` 位置。
- 保持现有 URL、片段锚点、标记类、字体、颜色、悬停行为和响应式规则不变。
- 从生成 HTML 中以机器方式验证完整的 16 项文案与目标地址契约。

**非目标：**

- 修改英文版章节内容、锚点或国家顺序。
- 修改法文首页导航或翻译英文 `Chapter` 文案。
- 增加 CSS、JavaScript 依赖、URL 重定向或运行时数据源。

## 决策

### 将章节编号作为显式国家元数据保存

每个英文国家记录增加 `chapterNumber`，例如 `3.1`，并渲染为 `Chapter ${chapterNumber} →`。

这让编辑文案与现有国家名和锚点位于同一处，便于按已发布英文版审查，且不会依赖对不透明 HTML 锚点字符串的解析。未选择从锚点推导编号，因为锚点格式服务于路由标识，而不是章节编号这一编辑契约；未选择单独的映射对象，因为那会把同一卡片的元数据拆分到两个位置。

### 将渲染变更限制在英文路径

英文渲染分支使用国家元数据生成文案；法文分支保留现有兼容文案与跳转逻辑。

这直接符合 UA-14 对已发布英文版的约束，也避免跨版本误改。

### 验证渲染结果，而非只搜索源代码字符串

国家卡片测试将生成一个全新的首页，并记录每张卡片的国家名、分析链接文字和 `href`，然后断言 16 条预期三元组。

这会验证用户实际看到的结果，并捕获遗漏条目、错误文案、映射顺序变化和目标地址变更。站点渲染脚本会更新代表性的静态断言，避免继续依赖已废弃的卡片标签。

## 风险 / 权衡

- **后续编辑变更了锚点或章节号之一。** → 完整的文案与 `href` 映射测试会失败，强制同时审查两个元数据值。
- **纯文字改动在窄视口意外换行。** → 不改 CSS 或标记尺寸，新文案不长于旧文案；完成后将在桌面、平板和移动宽度下检查。
- **误编辑生成的 public 文件。** → 只改生成器源文件和测试；验证通过 `npm run build:site` 重建产物。

## 迁移计划

1. 从更新后的源代码构建站点，并通过现有静态站点发布流程部署。
2. 不需要数据或 URL 迁移。
3. 如需回滚，恢复此前英文渲染标签及其测试后重新构建；现有链接在整个过程中保持有效。

## 开放问题

无。UA-14 已给出完整英文映射，并明确不改 URL。
