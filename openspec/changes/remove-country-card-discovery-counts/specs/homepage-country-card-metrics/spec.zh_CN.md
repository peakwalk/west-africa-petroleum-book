## 新增需求

### 需求：国家卡片只展示客观的在产油气田指标
生成的英文首页必须为全部 16 张国家卡片各渲染一个且仅一个国家摘要指标：该国的在产油气田数量及 Producing Fields 标签。国家卡片不得渲染发现数量、Discoveries 标签或任何等价的发现指标。

#### 场景：生成的国家卡片不包含发现数量
- **当** 生成英文首页时
- **那么** 16 张国家卡片中的每个指标列表都只包含一个在产油气田条目，且不包含发现指标条目

### 需求：国家卡片移除的范围仅限于国家卡片内容
系统必须为每张国家卡片保留国家名称、状态、国旗、部委/NOC 元数据、油气信息、国家分析链接及在产油气田数量。本变更不得删除国家卡片外的发现相关内容。

#### 场景：保留不相关的首页发现内容
- **当** 完成国家卡片变更后生成首页时
- **那么** 国家卡片发现指标不存在，同时国家卡片外不相关的首页发现内容保持不变

### 需求：国家卡片保持平衡和响应式能力
国家卡片布局必须使用统一的高度和间距处理，既不能留下原发现数量行的空隙，也必须保持国家分析链接可用。桌面、平板和移动端网格必须继续渲染全部国家卡片，不得出现裁切、重叠或按单个卡片设置的高度覆盖。

#### 场景：国家卡片在目标宽度下渲染
- **当** 在桌面、平板和移动端视口宽度检查生成的首页时
- **那么** 所有国家卡片均保持视觉平衡，内容清晰且可访问，响应式网格保持完整
