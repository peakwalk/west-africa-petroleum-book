## 背景

英文落地页由 `scripts/shared/homepage-content.mjs` 生成。当前唯一的 `COUNTRIES` 数组为 16 个国家同时存储在产油气田数量和发现数量，`renderCountryCard` 将两者分别渲染为 `.country-metrics` 中的一行。共享的国家卡片组件预留统一的最小高度，并将“国家分析”链接对齐在卡片底部。受影响的用户界面是英文首页；法文首页走兼容渲染路径，并不渲染这些国家卡片。

这个变更的事实边界很窄：从国家卡片移除一个主观统计项，同时保留客观的在产油气田数量及其他不相关的首页发现内容。

## 目标 / 非目标

**目标：**

- 在 16 张国家卡片中均只渲染一个客观指标：在产油气田数量。
- 从国家卡片的数据模型中删除过时的发现数量，避免其以后被意外重新渲染。
- 在桌面、平板和移动端保持卡片视觉平衡、等高、可访问且可用。
- 证明生成的 HTML 在任何国家卡片中都不含发现数量指标。

**非目标：**

- 不修改 Hero、页脚、搜索分类、地图、书籍章节或其他页面中的发现相关内容。
- 不重新定义或重新调研各国的在产油气田数量。
- 不重做国家卡片的信息架构、导航、状态徽标、国旗或响应式网格。

## 决策

### 让数据模型与模板保持一致

从每个国家项目中删除 `discoveries` 属性，删除本地化的发现数量标签，并从 `renderCountryCard` 移除第二行指标。

这样是在源头移除指标，而不是只用 CSS 隐藏它；可以防止过时、主观的数据继续留在生成 HTML 中，或被未来的卡片变体重新使用。

备选方案：用 CSS 隐藏发现数量行。未采用，因为内容仍会留在 DOM 中，可能被辅助技术和搜索索引读取，也可能在未来样式变更后重新出现。

### 保持既有的指标语义和卡片结构

保留单一在产油气田条目的 `dl`/`dt`/`dd` 指标结构；文章容器、标题、状态、油气列表和国家分析链接保持不变。

这是最小的语义改动，不会破坏既有 class hooks，并能让屏幕阅读器继续清楚理解指标关系。

备选方案：将定义列表换成自由文本。未采用，因为这会产生不必要的标记改动，也会弱化现有的指标关联。

### 用一条共享卡片高度规则重新平衡

只调整 `.country-card-v2` 的共享最小高度，以及删除一行后确有需要的垂直间距。保留底部对齐的国家分析链接和既有响应式网格规则。

一条共享规则让 16 张卡片保持统一，不出现针对国家或状态的特殊例外。最终数值将通过桌面、平板和移动端的生成页面检查确定，而不是仅根据被删除的行盲猜。

备选方案：按国家或状态设置高度覆盖。未采用，因为会形成脆弱的例外，且违背卡片等高要求。

### 测试实际渲染结果，而不只测试源代码字符串

新增聚焦生成首页的断言：统计 16 张国家卡片、要求每张恰有一个在产油气田指标，并在卡片片段中拒绝英文或法文的发现数量标签。现有完整站点渲染测试继续作为集成门禁。

这检查的是访问者实际收到的结果，并同时保护数据层与渲染层。

备选方案：只检查源文件中不存在 `discoveries:`。未采用，因为无法发现模板回归或等价的重新渲染路径。

## 风险 / 权衡

- [缩小固定高度可能让较长的国家标签或状态挤压底部链接] → 使用现有弹性网格布局，覆盖所有状态类别测试，并在各目标宽度下只调整一条共享最小高度规则。
- [宽泛文本搜索可能移除不相关的发现内容] → 将修改和断言限制在 `COUNTRIES`、`renderCountryCard`、卡片 CSS 及生成首页 HTML 的卡片片段中。
- [僵硬的视觉断言可能过度绑定 CSS 数值] → 断言语义输出和布局不变量；截图只用于选择与确认间距，不将任意像素值锁死到测试中。

## 迁移计划

1. 创建并校验 OpenSpec 文档。
2. 更新国家卡片数据模型与渲染模板。
3. 调整共享卡片布局并补充聚焦的渲染页面回归检查。
4. 运行聚焦测试、落地页构建/渲染套件，以及桌面、平板、移动端视觉检查。
5. 通过常规生成站点构建发布；无需数据迁移。

回滚很小：恢复被删除的数据字段和指标行，并恢复此前的共享卡片高度值。没有持久化数据、API 使用者或生成制品需要额外回滚。

## 开放问题

- 无。工单已明确限定为国家卡片内的移除，并要求卡片等高且响应式正常。
