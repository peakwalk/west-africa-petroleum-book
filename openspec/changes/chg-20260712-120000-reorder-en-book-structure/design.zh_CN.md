## 背景

UA-16 是英文版结构变更。票据中写作“石油开发管理”的目标章节，实际为现有 `chapter-10-petroleum-data-management-in-west-africa.md`。当前它排在第9章之后；确认后的顺序为第5章、第6章、作为第7章的数据管理、原第7/8/9章依次变为第8/9/10章，第11和第12章保持原编号。

mdBook 从 `SUMMARY.md` 派生阅读顺序、侧边栏和上一章／下一章链接。仓库另有手写目录、图表、表格和公式索引，以及按部分标题分类的章节库生成器。公开章节文件名是发布 URL，与显示编号相互独立。

## 目标／非目标

**目标：**

- 为英文读者提供已确认的学习顺序及匹配的第二、三部分标题。
- 保持可见章节编号、带编号标题、手写索引和正文交叉引用的一致性。
- 让规范章节 URL 与显示编号一致，通过跳转保留原路由，并重新生成所有派生产物。
- 仅改英文版、受版本控制的文本／配置，以及其单独管理的本地源参考 DOCX。

**非目标：**

- 不重写章节正文，不重新生成图表，不修改法文内容，也不手改 `public/`。
- 不将原先编号不匹配的章节 URL 保留为规范页面。

## 决策

### 以 `SUMMARY.md` 作为结构唯一来源

英文摘要会将数据管理源文件放在第6章之后，并从原第7章开始第三部分。这样 mdBook 会自动派生侧边栏与上下章导航，不维护第二份导航顺序。

考虑过仅调整生成 HTML；未采用，因为下一次构建会覆盖它，且源摘要仍会错误。

### 让规范文件路径匹配显示编号，并保留旧入口

四个受影响章节的源文件和规范公开路由使用修订后的第7至第10章编号。构建期跳转生成器会在原路由生成非规范页面，保留查询串和片段并将访问者带到对应规范路由。英法导航与 SEO 映射使用规范路由键。

考虑过无限期保留不匹配的文件名；未采用，因为路由名称必须描述其显示章节。重命名若无跳转会破坏入站链接，因此必须提供跳转。

### 对所有带编号内容采用明确映射

实施映射为：数据管理 `10 → 7`，石油财政制度 `7 → 8`，西非财政制度 `8 → 9`，社会政治决定因素 `9 → 10`。映射适用于章节标题、小节标签、公式标识、手写索引和有意的正文引用；不改变图表／表格本身的序号。

考虑过全项目宽泛文本替换；未采用，因为它可能错误修改历史陈述、URL 和无关数字内容。

### 第5章留在第二部分，变更仅作用于英文版

第5章仍属于第二部分：它当前属于该部分，若只将第6–7章放入第二部分会让它失去归属。法文版有独立的六章结构，不进行推测性重新编号。

考虑过逐字执行票据而省略第5章；未采用，因为每个章节都必须且只能归属一个部分。

### 在 OOXML 层直接同步英文参考 DOCX

源文件 `resources/editions/en/reference.docx` 仍保留原第7–10章顺序，导致 Markdown 迁移后按位置进行的 DOCX 检查会比较到错误章节。将完整的 DOCX 章节区块移至确认后的顺序，并把相同的显式编号映射应用于章节及小节标签。必须保留包内各部件和格式，只通过 DOCX ZIP/XML 包修改，且不使用 Microsoft Word 打开文件。

考虑过弱化或绕过公式覆盖校验；未采用，因为那会掩盖英文源文档与阅读版之间真实的不一致。

## 风险／权衡

- [带编号的页内锚点变化] → 更新内部手写索引链接并验证生成 HTML；旧数字锚点的外部深链接会成为已记录的破坏性变更。
- [规范章节 URL 变化] → 生成并测试保留查询串和片段的静态兼容跳转页；跳转页不进入站点地图。
- [手写索引偏离] → 按变更后的源标题重新生成章节区块，并逐一检查索引。
- [章节库生成器不认识新部分标题] → 在分类映射中加入新的英文第二、三部分名称，并验证生成的落地页。
- [直接编辑 OOXML 可能损坏 DOCX 或留下过期字段缓存] → 先写入临时包，再验证 ZIP／XML 结构和 DOCX 一致性／公式覆盖；随后用打包渲染器渲染并检查代表性页面。如有必要，设置字段在下次兼容办公软件打开时更新，但本流程不使用 Word。
- [参考 DOCX 是 Git 忽略的符号链接] → 不强制将其加入版本库，也不声称会随源代码变更一同推送。在仅依赖 Git 的发布可以视为完整之前，必须通过明确批准的制品流程分发或协调其外部目标文件。
- [无关工作区修改] → 保持图表资产和无关文件不动，完成前按路径审阅最终差异。

## 迁移计划

1. 更新英文源顺序和编号映射，再更新源索引和生成器识别。
2. 直接同步英文参考 DOCX，然后验证章节对齐和公式覆盖。
3. 构建站点至生成输出目录，验证导航、标题、锚点、路由和生成章节元数据。
4. 若验证失败，从临时备份恢复编辑前的参考 DOCX，并只回退本变更的源编辑后重建；可与重命名后的规范路由一起删除旧路由跳转映射。

- 无。用户已确认现有数据管理章节即 UA-16 所指目标。
