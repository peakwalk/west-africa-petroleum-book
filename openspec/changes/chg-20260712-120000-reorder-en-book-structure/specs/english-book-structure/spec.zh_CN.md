## 新增需求

### 需求：重排后的英文版章节顺序
英文版必须将数据管理章节紧接在第6章之后列出，并显示为第7章。原第7、8、9章必须分别显示为第8、9、10章；第5、11、12章保持现有显示编号。

#### 场景：读者按修订顺序阅读
- **当** 读者打开英文目录或章节侧边栏时
- **则** 其中第5至第12章依次为：第5、第6、数据管理第7、石油财政制度第8、西非财政制度第9、社会政治决定因素第10、第11和第12章。

### 需求：部分归属和标签保持连贯
英文版必须将第5章保留在第二部分，将第二部分命名为“Upstream Petroleum Operations and Development”，并从第8章开始第三部分，名称为“Petroleum Fiscal, Commercial and Economic Framework”。

#### 场景：每个受影响章节都有且只有一个部分
- **当** 读者查看英文摘要或生成的章节库时
- **则** 第5至第7章出现在第二部分，第8至第12章出现在第三部分。

### 需求：带编号内容和内部引用保持一致
英文的章节标题、带编号标题、手写目录、图表／表格／公式索引标题和有意的正文章节引用，必须使用修订后的章节编号映射。手写索引中的链接必须解析至匹配的生成章节和标题。

#### 场景：读者点击索引标题链接
- **当** 读者从英文手写索引选择受影响章节或带编号标题链接时
- **则** 链接打开的章节和标题显示与索引一致的编号。

### 需求：章节路由匹配显示编号并保留旧链接
英文版必须使用章节编号与修订后显示编号一致的规范源路径和生成章节 URL。四个重新编号章节的原 URL 必须保留为非规范跳转页，并保留查询串和片段。

#### 场景：请求规范章节 URL
- **当** 读者打开数据管理、财政制度、西非财政制度或社会政治章节的规范 URL 时
- **则** 其文件名编号与可见章节编号一致。

#### 场景：请求原章节 URL
- **当** 读者以查询串或片段打开四个重新编号章节之一的原 URL 时
- **则** 跳转打开对应规范章节，并保留查询串和片段。

### 需求：英文参考 DOCX 与修订后的顺序一致
英文源参考 DOCX 必须将数据管理章节紧接在第6章之后并显示为第7章，随后将财政制度、西非财政制度和社会政治章节依次显示为第8、第9和第10章。更新必须直接作用于 DOCX 的 OOXML 包，且不得使用 Microsoft Word 打开文件。

#### 场景：DOCX 一致性验证重新编号后的顺序
- **当** 根据已重排的英文 Markdown 章节检查英文源 DOCX 时
- **则** 公式覆盖和相关一致性检查识别到相同的章节内容与编号，且不会因旧的第7–10章顺序而遗漏公式渲染。
