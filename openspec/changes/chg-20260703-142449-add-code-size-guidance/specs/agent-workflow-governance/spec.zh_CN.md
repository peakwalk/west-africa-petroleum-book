## 新增需求

### 需求：代理必须用仓库级大小指导保持手写源码文件可审查
代理必须把手写源码文件大小视为仓库工作流规则。新建手写源码文件通常应保持在 600 行以内。落地页样式表、站点模板和页面生成脚本通常应保持在 500 行以内，并通过拆出有内聚性的局部样式、辅助模块、内容模块或更小的生成单元来控制体量。代理不得新增超过 800 行的手写源码文件，除非在变更总结中明确记录充分理由。对于已经超过适用阈值的手写源码文件，代理必须避免继续增加其行数；如果本次编辑是非平凡改动，则必须至少抽出一个有内聚性的单元，除非这样做会引入与当前任务无关的额外扰动。

#### 场景：新建仓库源码文件遵守通用默认阈值
- **当** 代理在本仓库中新建手写源码文件时
- **则** 该文件通常保持在 600 行以内，除非任务本身明确需要更多

#### 场景：落地页样式或生成脚本遵守更严格的仓库特定阈值
- **当** 代理新增或大幅扩展落地页样式表、站点模板或页面生成脚本时
- **则** 该文件通常保持在 500 行以内，并通过抽出聚焦的局部样式、辅助模块、内容模块或更小的生成单元来控制体量

#### 场景：已超限的大文件不能被随意继续做大
- **当** 代理编辑一个已经超过适用阈值的手写源码文件时
- **则** 代理避免继续增加其行数
- **并且** 当本次编辑属于非平凡改动时，至少抽出一个有内聚性的辅助单元、局部样式或模块，除非拆分会引入与当前任务无关的额外扰动

#### 场景：生成和机械产物继续豁免
- **当** 某个文件属于生成输出、锁文件、快照、夹具数据、第三方参考文件或迁移类产物时
- **则** 本仓库的文件大小指导不适用于该文件
