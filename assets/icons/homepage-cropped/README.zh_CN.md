# Homepage Cropped Icons

这个目录中的 WebP 文件才是当前仍在使用的生产资源，来源于已批准的 UA-3 icon board。

这个目录只用于展示类 / 内容类图标：
- homepage feature cards
- country intelligence signal rows
- audience cards

历史 PNG 交付副本已被刻意移除，不再保留在这个目录中。

不要把 control / UI icon 放在这里。
`Start Reading`、`Menu` 和 `Close` 仍必须保留在 `assets/icons/homepage-sprite.svg` 中，以便在按钮和导航场景里继续继承 `currentColor`。
