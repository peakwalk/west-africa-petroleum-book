# Homepage Cropped Icons

These PNGs are first-class production assets derived from the approved UA-3 icon board.

Use this directory only for display/content icons:
- homepage feature cards
- country intelligence signal rows
- audience cards

Do not place control/UI icons here.
`Start Reading`, `Menu`, and `Close` must remain adaptive SVG icons in `assets/icons/homepage-sprite.svg` so they inherit `currentColor` across button and navigation contexts.
